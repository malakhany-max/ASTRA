# ASTRA Companion — contracts (source of truth)

SHARED folder. The JSON wire schemas are read-only for service modules; coordinate schema changes with the team. `openapi.yaml` is generated by the backend contract script and must be regenerated after route changes.

All payloads are JSON. Timestamps are ISO-8601 UTC (`...Z`). Ids are strings.

| File | Schema id | Produced by | Consumed by |
|------|-----------|-------------|-------------|
| `reading.schema.json` | `astra.reading.v1` | simulators / hub ingest | security SDK |
| `integrity_result.schema.json` | — | security SDK | hub |
| `status.schema.json` | `astra.status.v1` | engine | hub, web |
| `security_event.schema.json` | `astra.security_event.v1` | security SDK | hub, ground |
| `exposure_record.schema.json` | `astra.exposure_record.v1` | engine / hub | ground |
| `envelope.schema.json` | `astra.envelope.v1` | security SDK / link | link, ground |
| `checkin.schema.json` | `astra.checkin.v1` | web-astronaut | hub |
| `consent.schema.json` | `astra.consent.v1` | web-astronaut | security SDK, hub |
| `plan.schema.json` | `astra.plan.v1` | engine | web |
| `openapi.yaml` | OpenAPI 3.1 | Hub, Ground Station, Companion, Link Simulator | web clients, integration tooling |

`openapi.yaml` is generated from the backend FastAPI route declarations by
`python backend/ground-backend/generate_openapi.py`. Review route ownership and payload
parity when service contracts change; the JSON schemas in this folder remain
the source of truth for their wire payloads.

## Canonical JSON (for signatures)

Keys sorted, no whitespace, UTF-8:

```python
json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=False).encode("utf-8")
```

The `sig` field is **excluded** before canonicalization (it signs "all other fields").
